# C语言程序设计—学习实验室

面向本科学生的互动学习网站，参考谭浩强《C程序设计》第五版，按本课程教学需要组织为十章。第二章重构为“数据存储与运算”。

## 公开网站

本仓库使用 GitHub Pages 发布，正式地址为：https://jdd-jdd.github.io/c-learning-lab/

手机、平板和电脑均可使用现代浏览器访问，无须登录 GitHub。页面由 GitHub 托管，不依赖教师电脑开机，也不要求师生处在同一个 Wi-Fi。网站可用性受 GitHub 服务和访问网络影响。

## 本版内容

- 十章应用情境、核心交互实验、程序过程演示、学习目标、自测与笔记。
- 六十个补充知识点，可自主选择学习。
- 每章最后提供学习指南，支持三条学习路线、学习自评与反思。
- 第五章包含充电柜温度巡检、宿舍楼应急灯巡检和 break 改进案例。
- 附录提供五款趣味小游戏，共二十一关。
- 电脑端显示左侧目录；手机端点击左上角菜单展开目录。

## 互动与学习记录

程序执行是配套 C 代码的可视化模拟，不是任意 C 代码的在线编译器。案例中的设备、阈值和控制操作用于教学模拟，不连接真实设备。

昵称、完成进度、实验笔记、自测、指南和游戏记录保存在当前浏览器，可导出 CSV；更换设备、浏览器或清除浏览器数据后，不会自动同步。网站无须填写账号密码，也没有教师端集中统计。

## 维护

发布源为 `main` 分支根目录。保留 `.nojekyll`、`index.html` 及所有配套 JavaScript、CSS 和 `for-loop.html` 文件。更新后等待 GitHub Pages 完成构建。

二维码位于 `assets/`，指向网站首页；可以下载后放入 PPT 或课堂通知。
